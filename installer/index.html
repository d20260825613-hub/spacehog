spacehog

Find out what is eating your disk. Duplicates, big files, junk, empty folders.

Windowsrecommended

One file, no installer, no Node needed. Download it, then run it from a terminal:

Download spacehog.exe Checksums

Then point it at a folder. Nothing is ever deleted, so it is safe to run anywhere:

spacehog.exe C:\Users\you\Pictures
Windows SmartScreen will warn you the first time, because the binary is not code-signed (a certificate costs money). Choose More info, then Run anyway. You can also right-click the file, pick Properties, and tick Unblock.

Linuxbinary

A static single-file binary. No Node, no packages to install:

curl -L -o spacehog https://github.com/d20260825613-hub/spacehog/releases/latest/download/spacehog
chmod +x spacehog
./spacehog ~/Pictures

It is unsigned and untested on every distribution. If your shell refuses to run it, the npm route below always works.

Any platform, via npmneeds Node 18+

npx spacehog .

Or install it once:

npm install -g spacehog
spacehog ~/Downloads

First run, three useful commands

  1. spacehog .
    Everything in the current folder, biggest items first.
  2. spacehog . --keep oldest
    The same, but every duplicate group tells you which copy to keep.
  3. spacehog . --json > report.json
    Machine-readable output for a script or a dashboard.

Press Ctrl C to stop a long scan. Nothing is written except a small hash cache, and --no-cache turns even that off.
